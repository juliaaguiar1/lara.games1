Lara Games — Plataforma de Jogos Brasileiros

O projeto Lara Games consiste em uma plataforma dedicada à divulgação e valorização de jogos brasileiros.
Desenvolvido como parte da Fase 3 — Atividade 02 do curso Design Web — FIAP, o trabalho tem como foco a aplicação da identidade visual, acessibilidade e responsividade em ambiente web.

Objetivo do Projeto

O principal objetivo é aplicar a identidade visual desenvolvida anteriormente e construir páginas web utilizando HTML5, CSS3, Bootstrap 5 e JavaScript, com foco em:

Identidade visual coerente com a proposta da marca.

Design responsivo e compatível com múltiplos dispositivos.

Acessibilidade e boas práticas de usabilidade.

Organização e clareza de código.

Tecnologias Utilizadas
Tecnologia	Finalidade
HTML5	Estrutura semântica do conteúdo
CSS3	Estilização e aplicação da paleta de cores
Bootstrap 5	Responsividade e componentes estruturais
JavaScript	Funcionalidades interativas e acessibilidade
LocalStorage	Armazenamento de preferências do usuário
Recursos de Acessibilidade

Modo de alto contraste.

Ajuste de tamanho de fonte.

Navegação completa via teclado.

Estrutura semântica com header, main, nav, footer.

Textos alternativos e atributos ARIA para leitores de tela.

Link “Pular para o conteúdo principal”.

Feedback visual em formulários e alertas de interação.

Páginas Desenvolvidas
Página	Descrição
Home / Loja	Apresenta os principais jogos brasileiros disponíveis.
Meus Jogos	Biblioteca pessoal do usuário.
Cadastro	Formulário com validação e recursos de acessibilidade.
Fórum	Espaço de interação entre usuários.
Suporte	Canal de contato com a equipe da plataforma.
Usuário	Página de perfil e dados pessoais do jogador.

As páginas obrigatórias (Home e página adicional) foram entregues com layout unificado e coerente.

Identidade Visual

Tema escuro com detalhes em azul neon e branco.

Logotipo com destaque para “Lara” em branco e “Games” em azul, acompanhado de uma curva azul inferior feita em CSS.

Tipografia moderna e de fácil leitura (Arial / Sans-serif).

Layout minimalista e funcional, com hierarquia visual clara.
